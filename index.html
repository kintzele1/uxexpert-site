FAQ

Common questions about AI UX audits

What is an AI UX audit?
An AI UX audit uses an AI model to review a website or web app the way an expert would — checking usability, accessibility, code quality, performance, and conversion — and returns prioritized, actionable findings. UXexpert.ai runs three lenses at once: a principal UX design review, a full-stack engineering code audit, and a growth strategist's conversion analysis.
What does UXexpert.ai check?
Every audit covers design and usability, accessibility mapped to WCAG success criteria, engineering and code quality, performance signals, SEO fundamentals, and conversion. Each finding comes scored by severity, effort, and impact, with a concrete fix — often a code snippet you can paste in.
Is my code private?
Yes. The local engine runs entirely in your browser — the code you paste, upload, or fetch never leaves your device. The optional Claude AI engine only sends data if you supply your own Anthropic API key, and it goes directly from your browser to Anthropic, never through our servers.
Do I need an API key?
No. The local engine is free and needs no key or account. An Anthropic API key is only required for the deeper Claude AI review, which you bring yourself. Founding Pro will later add hosted reviews that need no key of your own.
How is this different from Lighthouse or an accessibility checker?
Single-purpose tools check one dimension — Lighthouse for performance, axe for accessibility. UXexpert.ai combines a usability, engineering, and growth review in one report, adds AI reasoning that reads your code and screenshots in context, and lets you tune the audit to your specific users with expertise skills. It complements those tools rather than replacing them.
Can it audit a live URL or a GitHub repository?
Yes. Paste a live URL and UXexpert fetches the page for review, or point it at a public GitHub repository — a branch or folder link works too. A GitHub token unlocks private repositories. You can also drag in files or screenshots directly.
Is there a free version?
Yes — the local engine is free forever, with unlimited audits, expertise skills, custom rules, and Markdown export. Founding Pro ($19/month, rate locked for life) adds early access to hosted reviews, saved history, and richer exports as they ship.
